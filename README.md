# CI2026_lab3
This is the repo for lab 3 of Computation Intelligence course 2026/2027

there are N children, each child has C Boolean characteristics, such as tall, thin, etc.
the difference between two children is the number of characteristics on which they differ.
the children stand in a circle holding hands.
to maximize their enjoyment, we want to arrange them so as to maximize the sum of the differences between adjacent children.
Given n children, each represented by a binary vector of length c, the distance between two children is their Hamming distance.
Arrange the children on a circle so as to maximize the sum of the Hamming distances between consecutive children
